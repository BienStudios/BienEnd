## ¿Por qué Java (JDK 25 LTS) y Spring Boot (MVC 4.1.1)?

Java es el lenguaje por excelencia de backend web, ya que apoyado en Spring Boot, permite un desarrollo rápido e integrativo, con librerías y decoradores que hacen la mayor parte del proceso interno de un Servidor. Al integrar librerías dedicadas al OAuth, a los JWT y ser altamente configurable para términos de seguridad, además de contar con una enorme comunidad de desarrolladores con mucha experiencia en el tema y una amplia documentación de apoyo, lo hemos considerado como una de las mejores opciones para el registro de usuarios y autenticación.
